# Face-Recognition-System-With-Greetings
Required files to run the code 
Installation required in terminal
✅ Modules to Install
| Module              | Install Command                   | Purpose/Notes                                           |
|---------------------|------------------------------------|---------------------------------------------------------|
| opencv-contrib-python | pip install opencv-contrib-python | Required for `cv2.face.LBPHFaceRecognizer_create()`     |
| numpy               | pip install numpy                 | For handling arrays and loading `.npy` label files      |
| gTTS                | pip install gTTS                  | Google Text-to-Speech for voice greeting generation     |
| pygame              | pip install pygame                | Plays the generated `.mp3` 


🔄 Final Installation Command (All in One):
pip install opencv-contrib-python numpy gTTS pygame
